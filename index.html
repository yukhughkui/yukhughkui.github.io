Stack & Principles

技术栈与做法

不追新，够用就好。以下是这些项目里真正用到的东西。

Languages

  • Python 模型 / 实验
  • JavaScript 交互逻辑
  • HTML · CSS 单文件网页
  • Kotlin Android

Tools

  • YOLOv8 实时检测
  • CBAM · Grad-CAM 可解释性
  • PCA · 集成分类 降维与识别
  • SPC 控制图 统计可视化

Principles

  • 本地优先 不依赖服务器
  • 单文件优先 打开即用
  • 数据可见 结果要能看懂
  • 少即是多 不打扰人

About

关于

「把想法做成点开就能用的东西。」

这些项目大多从一个很具体的念头开始：想看一眼今天碰了多少次屏幕，想把一串数据直接变成控制图，想让习惯记录别那么像打卡。做完、能打开、能被用一次，比做得大而全更重要。

所以这里没有复杂部署，也没有需要注册才能试的东西。多数是一个 HTML 文件，存下来双击就能跑；模型实验也都留着可复现的对比与结果。
